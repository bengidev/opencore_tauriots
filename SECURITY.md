# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, report it privately by opening a [GitHub Security Advisory](https://github.com/bengidev/opencore_tauriots/security/advisories/new) or contacting the maintainer directly.

Include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

We aim to acknowledge reports within 72 hours and will work with you on a responsible disclosure timeline.
